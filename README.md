# DecodeLabs Project 2: Iris Flower Classification Using KNN

![Iris Flower Classification Using KNN](images/iris-knn-cover.png)

This project implements a K Nearest Neighbors (KNN) classification model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

## Project Overview

The project follows a complete basic machine learning workflow, starting from dataset loading and preprocessing and ending with model evaluation and visualization.

## What I Implemented

1. Loaded the Iris dataset using Scikit learn
2. Explored the dataset and checked for missing values
3. Encoded the flower species into numerical labels
4. Normalized the feature values using MinMaxScaler
5. Split the dataset into training and testing sets
6. Trained a K Nearest Neighbors classifier
7. Generated predictions on unseen test data
8. Evaluated the model using accuracy and classification report
9. Visualized the classification results
